# Firm AI Use Policy Package

Materials page for the model firm AI use policy package (research assistance to Suzanne Babb's firm).

**Intended live page:** https://johnakelly-yahoo-com.github.io/e1066-firm-ai-policy-2026/

## Contents

- `index.html` — landing page styled to match law-kelly.com / blog.law-kelly.com (same template as e1066-mcle-scba-2026)
- `docs/` — 25 PDFs: the eleven policy-package documents (rendered from Folder 42), the presentation deck and glossary (Folder 47), and the twelve product policy documents plus cost sheet (Folder 49)
- `thumbnails/` — first-page previews for the cards
- `videos/` — drop `walkthrough.mp4` here when filmed, then activate the video card per the comment in `index.html`

## Rebuilding

`../04 build_site.py` regenerates `docs/` and `thumbnails/` from the source folders. Rerun it whenever a source document changes, then commit.
